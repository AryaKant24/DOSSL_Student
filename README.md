# Student Task Manager

A simple and responsive web application for students to manage their tasks, assignments, and deadlines.

## Features

* Add tasks
* Add subject and due date
* Set task priority
* Mark tasks as completed
* Delete tasks
* View total, pending, and completed tasks
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```text
student-task-manager/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

### 1. Clone the repository

```bash
git clone <repository-url>
cd student-task-manager
```

### 2. Start a local server

If Python is installed:

```bash
python3 -m http.server 8000
```

### 3. Open in browser

Go to:

```text
http://localhost:8000
```
